# YB Connect

Créer une plateforme digitale complète, moderne et professionnelle pour YB COMPANY, entreprise marocaine basée à Casablanca spécialisée dans la production textile, l’habillement, la sublimation, l’industrie publicitaire, l’impression, les supports publicitaires, la sacherie et les solutions de communication visuelle.

Le projet comprend 2 interfaces principales reliées entre elles :

Un nouveau site web commercial YB COMPANY intégrant un Agent IA Service Client.

Un Dashboard Administrateur permettant de centraliser le service client, les conversations, les rendez-vous et un Agent IA Community Manager.

L’objectif principal est de transformer le site YB COMPANY en véritable outil commercial capable de présenter les services, récupérer des prospects, qualifier automatiquement leurs demandes, prendre des rendez-vous et centraliser les demandes provenant du site et des réseaux sociaux.

29. OBJECTIF FINAL DU PRODUIT

Le parcours attendu est :

Réseaux sociaux / Google / site → visiteur → Agent IA → qualification → récupération des coordonnées → demande commerciale ou rendez-vous → équipe YB COMPANY.

En parallèle :

YB COMPANY → Agent Community Manager IA → idées → création des publications → validation → planification → publication → analyse des performances.

Nous voulons donc une plateforme qui combine :

Site commercial

Agent IA Service Client omnicanal

Prise de rendez-vous

Gestion des prospects

Community Manager IA

dans une expérience cohérente et centralisée.

Commencer par réaliser une version frontend complète, premium et fonctionnelle de l'ensemble de cette plateforme, avec navigation réelle entre les pages, données de démonstration cohérentes et composants réutilisables.

La priorité UX est la simplicité : YB COMPANY doit pouvoir comprendre l'état de son activité en quelques secondes et accéder rapidement aux conversations clients ou à la création d'une publication.
